# 🖤 Projeto de Binarização de Imagem com Python (Jupyter Notebook)

Este projeto demonstra como **converter uma imagem colorida no formato PPM (P3)** para:
1. **Escala de Cinza (0 a 255)**  
2. **Binarizada (Preto e Branco - 0 e 255)**  

O código foi feito **sem uso de bibliotecas externas**, apenas com Python puro.
